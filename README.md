NETFLIX CUSTOMER CHURN ANALYSIS

PROJECT OVERVIEW
This project analyses customer churn patterns using a netflix customer datasets. The goal is to identify customer groups with higher churn rates and provide business recommendations.
OBJECTIVES
*Calculate the overall customer churn rate.
* Analyse churn by subscription type.
*Compare churn across different regions.
*Analyse churn by device and payment method.
*Understand churn patterns by favorite genre.
*Suggest strategies to improve customer retention.

TOOLS AND TECHNIQUES
*Python 
*Pandas
*Matplotlib
*Seaborn
*Jupyter notebook
*CSV Dataset

Dataset
This project uses a customer churn dataset containing 5000 records.
The target column is churned:
*1= Customer churned
*0= Customer retained

KEY FINDINGS
*Overall churn rate: approximately 50.3%.
*Basic subscription showed the highest churn rate.
*Europe and south america had relatively higher churn.
*Laptop users showed the highest churn among devices.
*Crypto and gift card payment methods showed relatively high churn.

BUSINESS RECOMMENDATIONS
1. Review the pricing and benefits of basic subscriptions.
2. Investigate customer experience in higher churn regions.
3.Improve the laptop viewing experience.
4. Review payment related issues.
5.Introduce personalised recommendations and retention campagins.
